# PDA Expression Validator

A web tool to validate and visualize arithmetic expressions using a Pushdown Automaton (PDA).

## Features
- **Syntax Validation**: Checks arithmetic expressions with variables (a-z), operators (+, -, *, /), and parentheses.
- **Step-by-Step Trace**: Visualizes PDA stack, operator stack, and parse tree construction.
- **Parse Tree Visualization**: See the parse tree for valid expressions.
